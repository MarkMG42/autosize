# Авторазмер длинных кромок рамы — SolidWorks 2025

`AutoDimensionFrame.bas` — исходный VBA-модуль. Работает с одним выбранным видом **сборки** на активном листе чертежа. Для каждого видимого тела каждого экземпляра компонента выбирает самую длинную доступную прямую кромку и пытается создать связанный с ней размер. Многотельный сварной элемент обрабатывается по телам, повторяющиеся экземпляры — отдельно.

Это размер **кромки**, а не расстояние между торцами детали, не длина профиля из спецификации и не габарит всей рамы. Цепочки 50/541, расстояния между деталями и полный набор размеров с картинки не строятся. Скрытые тела и тела без подходящих видимых прямых кромок не получают размера. Частично закрытая деталь может иметь доступную кромку короче полной длины детали.

## Запуск

1. Работайте на копии чертежа. Откройте его в SolidWorks 2025; модели должны быть доступны, компоненты разрешены, чертёж не в Detailing Mode.
2. Создайте VBA-макрос через **Tools → Macro → New**. В редакторе VBA импортируйте `AutoDimensionFrame.bas` (**File → Import File**). Используются штатные ссылки SolidWorks Type Library и Constant Type Library. Точка входа — `AutoDimensionFrame.main`.
3. Для изометрического вида в его свойствах установите тип размеров **True / Истинные**. Макрос отказывается работать с Projected: проекционная длина наклонного ребра короче истинной. Свойство вида автоматически не меняется; его изменение пользователем может повлиять и на существующие размеры этого вида.
4. Выберите ровно один вид, щёлкнув его рамку, и запустите `main`. Не выбирайте ребро вместо вида.
5. Проверьте результат и журнал **Immediate Window** (`Ctrl+G` в VBA): количество созданных, пропущенных и неудачных операций. Сохранение документа выполняется вручную.

Параметры в начале модуля: `OFFSET_M = 0.008` — отступ текста 8 мм на листе; `MIN_LENGTH_M = 0.02` — минимальная длина ребра 20 мм в модели; `MIN_PROJECTED_M = 0.001` — минимальная длина проекции 1 мм на листе. Размер строится около середины ребра со стабильной стороны. Автоматического устранения наложений, выноса за границы листа или оптимизации компоновки нет; текст можно переместить вручную.

## Повторный запуск и частичные ошибки

Перед изменением геометрических аннотаций макрос добавляет текстовое пользовательское свойство чертежа `AutoFrameDim:<имя листа>:<имя вида>` с временем запуска. Это постоянный предохранитель от дублирования; он сохраняется вместе с документом. Существующее свойство не перезаписывается. После запуска без созданных размеров предохранитель удаляется, если не остался размер с неудачным удалением.

Повторный запуск для того же имени листа/вида блокируется. Для повторения **сначала вручную удалите размеры предыдущего запуска**, затем удалите соответствующее свойство через **File → Properties → Custom**. При частичном успехе правило такое же. Переименование листа/вида обходит этот предохранитель — перед запуском на переименованном виде самостоятельно проверьте прежние размеры. Чужие/существовавшие размеры не распознаются и не удаляются; предохранитель не является распознаванием совпадающих размеров.

После создания проверяется считанная длина размера против длины прямого ребра (допуск 0.001 мм). Если размер проекционный или readback не получен, макрос пытается удалить **только что созданный** размер. При неудаче удаления обработка останавливается, предохранитель остаётся; требуется ручная проверка. Частично успешный запуск оставляет корректно созданные размеры. Документ автоматически не сохраняется; макрос очищает текущий выбор. Опция ввода значения при создании размера временно отключается и восстанавливается при штатном завершении/обработанной ошибке; аварийный останов VBA кнопкой Reset может помешать восстановлению.

## Что проверено и что необходимо проверить в SolidWorks

В Linux возможны только статические проверки исходника. VBA-компиляция, COM-вызовы и поведение SolidWorks 2025 здесь **не выполнялись**. API-проверка агентом не заменяет запуск на Windows. Доступ к официальной документации в этой сессии также блокировался недоступным прокси.

Перед применением к рабочим чертежам:

- Выполните **Debug → Compile** в редакторе VBA SolidWorks 2025.
- На простой сборке из двух прямоугольных деталей известной длины сравните размер в обычном и изометрическом видах. В изометрии он должен совпадать с полной длиной кромки, а не её проекцией.
- Проверьте повёрнутый компонент, вложенную подсборку, несколько экземпляров одной детали и многотельную сварную деталь. Особенно проверьте положение текста: точки кромок из контекста вида преобразуются только через `ModelToViewTransform`, без повторного `Component2.Transform2`. Это предположение о контексте координат требует нативного подтверждения; проверка численного значения размера сама по себе положение текста не проверяет.
- Проверьте масштаб вида/листа, скрытые компоненты, короткие и кривые кромки, отсутствие выделенного вида, выбранное ребро вместо вида и Projected-режим.
- На копии чертежа проверьте повторный запуск, сохранение/повторное открытие и сохранность ранее существовавших размеров. Сверьте каждый созданный размер с нужным телом и кромкой.

Разрезы, разрывы, обрезанные/детальные виды, exploded view, виртуальные компоненты, lightweight/неразрешённые модели и виды отдельной детали не заявлены как поддерживаемые. Макрос не выбирает по изображению «профиль»: болты и пластины с достаточно длинной прямой кромкой тоже могут получить размер.
