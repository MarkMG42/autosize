# Проба одного размера по списку вырезов — v1.1

`FrameCutListDimensionTrial.bas` — отдельный самостоятельный VBA-модуль.
Он создаёт **один** настоящий размер выбранного продольного ребра тела рамы,
после проверки его длины по списку вырезов. Это следующий этап после Probe,
а не массовая расстановка всех размеров. Другие компоненты сборки не обрабатываются.

## Подтверждённые исходные данные

Полный журнал Probe v1.1 подтвердил работу на виде сборки: выбран экземпляр
многотельной детали рамы, конфигурации совпали, прочитаны 17 позиций списка
вырезов и 27 тел без ошибок. Для всех 27 тел `ДЛИНА × 0.001` совпала с длиной
максимального прямого ребра в метрах. Выбранное ребро и его преобразование
в исходную деталь были прямыми и имели одинаковые вершины и длину 710 мм.

Это подтверждает чтение исходных данных для данного примера. Создание и
размещение размеров в изометрии этим журналом ещё не проверены.

## Исправление v1.1

Нативный журнал v1.0 показал противоречие: `SOURCE EDGE ... IsLine=True`,
сразу после этого — отказ «Selected source edge is not straight». Размер
создать не пытались. Код дважды вызывал `IsLine` и использовал `Not CBool(...)`.

В v1.1 `IsLine` читается один раз. Исходное значение журналируется с `TypeName`,
`VarType` и числовым представлением; затем нормализуется сравнением с `False`.
Отказ проверяет тот же сохранённый результат. `Identity` тоже читается один раз,
но не подменяет ответ `IsLine`.

Такая обработка устраняет повторный вызов и зависимость отрицания от внутреннего
представления COM Boolean. Гипотеза о нестандартном True=1 вместо VBA True=-1
согласуется с журналом, но подтвердить её должен числовой вывод v1.1.

Аналогично обработаны ответы выбора ребра, перемещения/выбора аннотации,
удаления, настройки ввода и выходные флаги свойств `wasResolved`/`linked`.
Проверки геометрии, списка вырезов, значения, положения и откат сохранены.

## Запуск

1. Импортируйте **FrameCutListDimensionTrial.bas** в проект макроса SolidWorks.
   Модуль самостоятельный: старый AutoDimensionFrame и Probe для запуска
   не требуются. Нужны стандартные ссылки SldWorks и SwConst.
2. Выполните Debug → Compile.
3. На копии чертежа сборки выберите **одно прямое продольное ребро самого тела
   рамы**, длина которого равна длине элемента в списке вырезов. Для первого
   испытания используйте то же ребро 710 мм, которое было в успешном Probe.
   Дополнительное выделение рамки вида допускается; несколько рёбер — нет.
4. Запустите `FrameCutListDimensionTrial.main`.
5. Проверьте число 710, привязку к нужному телу, направление размерной линии
   и расстояние надписи от профиля. Пришлите файл журнала из TEMP и снимок результата.

Тип размеров изометрического вида должен быть **True / Истинный**, как требовала
прежняя версия. Программа не меняет эту настройку автоматически. Если режим
Projected / Проекционный, она сообщит об этом до создания размера.

## Проверки и границы

- Выбранный компонент разрешается в дерево исходной сборки с сохранением пути
  вложенности; проверяются конфигурации. Вид отдельной детали также допускается.
- Ребро переводится непосредственно в контекст исходной детали, затем его тело
  ищется в папках списка вырезов. Старого перебора LocalMember по всем рёбрам нет.
- Требуется ровно одно совпадение тела с позицией списка вырезов. Проверяется
  идентичность тела; имя служит дополнительной проверкой, а не заменой идентичности.
- Свойство длины определяется по точному токену ссылки `LENGTH@@@`, независимо
  от русского названия `ДЛИНА`. `TOTAL LENGTH` не используется. Свойства читаются
  из кэша; требуется разрешённое связанное значение (`wasResolved=True`,
  `linked=True`).
- Поддержан положительный десятичный текст с точкой или запятой, без суффиксов
  единиц. В этом испытании длины списка вырезов считаются **миллиметрами**:
  коэффициент 0.001 подтверждён двумя журналами пользователя. Совпадение с
  геометрической длиной выбранного ребра проверяется до создания размера.
- Размещение ищется рядом с проекцией ребра. Выход за контур тела и прямоугольник
  вида допускается; остаётся ограничение листа. Площадь текста оценочная:
  это не гарантия отсутствия пересечений всех выносных линий, геометрии и заметок.
- Вызов создания выполняется не более одного раза. Значение размера проверяется
  после создания и после окончательного перемещения надписи. Число и отображаемый
  текст не подменяются. Неудачная новая аннотация удаляется; неопределённый исход
  создания/удаления явно отмечается для ручной проверки.
- Старые размеры сохраняются. Повторный запуск может создать дубликат.
- Документ не сохраняется, конфигурации не переключаются, список вырезов не
  обновляется. Временная настройка ввода значения размера восстанавливается.
- Скошенные элементы, у которых ни одно продольное ребро не равно длине списка
  вырезов, требуют отдельного способа привязки. Этот Trial не подменяет их длину
  размером короткого ребра или текстовым override.

## Статус проверки

Исходник проверяется статически и по доступным метаданным API. Версия 1.0
запускалась в SolidWorks 2025 и остановилась до создания размера на проверке
Boolean-ответа `IsLine`. Выполнение v1.1 в SolidWorks 2025 ещё не подтверждено. До результата этого испытания массовый
обход 27 тел не объявляется рабочим.
