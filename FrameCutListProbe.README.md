# Проверка только тел детали рамы — v1.1

Уточнённая задача: изометрический вид сборки содержит одну многотельную деталь
«Рама №2» и отдельные уголки, ножки, проушины и другие компоненты. Образмерить
нужно только тела детали «Рама №2», по длинам её списка вырезов.
Надписи допустимо размещать снаружи контура тела.

`FrameCutListProbe.bas` — отдельная диагностическая программа для следующего
согласованного шага. Она не создаёт размеры. Прежний `AutoDimensionFrame` 2.4.3
ещё не реализует уточнённый отбор по списку вырезов и не является исправленной
версией для этой задачи.

## Подтверждённый результат и следующий шаг

Получен полный журнал v1.1 из сборочного вида: выбрана многотельная деталь рамы,
прочитаны 17 позиций списка вырезов и 27 тел, ошибок нет. Длины `LENGTH` совпали
с максимальными прямыми рёбрами всех 27 тел; выбранное ребро 710 мм и результат
его преобразования в исходную деталь совпали.

Следующий этап — [FrameCutListDimensionTrial](FrameCutListDimensionTrial.README.md):
один настоящий размер по выбранному продольному ребру со сверкой по списку вырезов.
Повторять Probe на этом же примере для начала испытания одного размера не требуется.

## Как проверить

1. Импортируйте **FrameCutListProbe.bas** в VBA-проект SolidWorks со стандартными
   ссылками SldWorks и SwConst. Имя нового модуля отличается от старого.
2. Откройте чертёж сборки и выберите **одно заведомо прямое ребро тела самой
   детали «Рама №2»** на нужном изометрическом виде. Не рамку вида и не ребро
   отдельного уголка/ножки/проушины.
3. Выполните Debug → Compile. Вернитесь в окно чертежа, нажмите Esc и выделите
   ребро обычным щелчком. Запустите `FrameCutListProbe.main` через
   Инструменты → Макрос → Выполнить, чтобы проверить сохранение выбора при запуске.
   В v1.1 рамка вида или другие не-рёберные объекты в выборе не мешают, если
   настоящее ребро ровно одно. Несколько рёбер программа не выбирает произвольно.
4. Макрос сообщит путь текстового журнала в системной папке TEMP. Пришлите этот
   файл полностью: он сохраняется в Unicode, чтобы имена на русском не искажались.
   Если создание файла недоступно, журнал останется в VBA Immediate (Ctrl+G).

## Независимый способ без выбора ребра

Если SolidWorks теряет выделение при запуске, откройте **сам файл детали
«Рама №2»** и сделайте его активным документом. В VBA запустите отдельную
процедуру **`FrameCutListProbe.ProbeActiveFramePart`**. Она прочитает список
вырезов и тела активной детали без выбора ребра и без обращения к другим
компонентам сборки.

Этот способ не проверяет преобразование ребра чертежа в исходную деталь.
В журнале будет явно указано `MODE=active part only; drawing edge/context test
NOT performed`. Название, путь и активная конфигурация детали выводятся,
чтобы можно было проверить правильность открытого файла.

## Исправление обработки выбора v1.1

Сообщение v1.0 означало только, что `GetSelectedObjectCount2(-1)` вернул не 1.
Из двух прежних STOP нельзя установить, было ли выделений 0 или несколько.
В v1.1 до проверки выводятся `SELECTION total`, типы объектов, их drawing-view,
число рёбер и число остальных выделений. При нуле программа не угадывает
компонент; при нескольких рёбрах сообщает неоднозначность.

## Область обследования

Макрос разрешает выбранный экземпляр в дереве сборки и читает **только его
исходную деталь**. Для проверки выбора в журнале есть название, путь файла,
конфигурация и число твёрдых тел. Другие детали сборки не обследуются на размеры.
При несовпадении активной конфигурации с требуемой программа сообщит об этом;
самостоятельно переключать конфигурацию она не будет.

## Что будет в журнале

- Для выбранного ребра и результата преобразования в деталь — тип кривой,
  `IsLine` и координаты вершин. Это проверка наблюдавшегося в 2.4.3 противоречия
  «в виде прямое, после сопоставления не прямое».
- Все папки типа `CutListFolder` выбранной детали, их тела и свойства.
- Имена свойств, исходные выражения, разрешённые значения, статусы `Get6`,
  `wasResolved` и `linked`. Название свойства длины и единицы заранее не угадываются.
- Число прямых рёбер и длина максимального прямого ребра каждого тела **в метрах**
  из локальной геометрии. Эта длина не объявляется длиной элемента списка вырезов:
  при скосах и обработке они могут различаться.

Свойства читаются с `UseCached=True`; неразрешённые/несвежие значения могут
потребовать отдельной проверки в интерфейсе SolidWorks. Программа не обновляет
список вырезов, не перестраивает и не сохраняет документы, не изменяет выбор
и не создаёт аннотации. Единственный создаваемый файл — новый диагностический
журнал; существующие файлы не перезаписываются.

## Проверка в облаке

Статически проверены структура VBA и сигнатуры используемых методов по
метаданным SolidWorks Interop 32.1.0. Версия 1.0 запускалась пользователем,
но остановилась до чтения ребра на проверке общего количества выделений.
Выполнение v1.1 в SolidWorks 2025 ещё не проверено.
Нужен результат этого запуска, чтобы выбрать подтверждённое свойство длины и
привязку размера, прежде чем возобновлять массовую расстановку.
