# Размеры рамы: кэш исходных продольных рёбер

`FrameCutListDimensionsV3.bas` v3.0 — отдельный самостоятельный модуль SolidWorks
VBA. Рабочая [версия V2.2](FrameCutListDimensionsV2.README.md) сохранена: её
пользовательский запуск создал 17 размеров из 19 без ошибок итоговой проверки.

## Почему V2.2 пропустила два тела

Журнал `FrameCutListDimensionsV2-radA8A7D.tmp.txt` завершён штатно:
`created=17; skipped=2; failed=0; blocked=False`. Общий лимит подготовки труб
30 секунд истёк при обработке `Вырез-Вытянуть117` (340 мм). Его частичные
кандидаты были отброшены; до `Вырез-Вытянуть130` (270 мм) очередь не дошла.
Это срабатывание лимита, а не установленная ошибка геометрии этих труб.

## Изменение в V3

Начальная проверка `ValidateLengthDirection` уже читает исходные рёбра каждого
тела, находит прямые рёбра полной длины `LENGTH` и проверяет их параллельность.
V3 сохраняет их в отдельном кэше задания **после полной успешной проверки**.
Для поиска границ скруглений больше не нужны повторный обход всех граней тела
и попарное сравнение их идентичности.

Для труб без обычных видимых кандидатов проверяются только рёбра этого кэша:
принадлежность исходному телу, полная длина, соседство плоскости и цилиндра,
проекция и соответствие выбранному экземпляру сборки. Предпочтение более
наружной границе остаётся геометрической эвристикой. Видимость исходного ребра
не гарантируется; выбор, истинное значение, привязка и отсутствие dangling
проверяются до и после создания.

Кэш ограничен 256 рёбрами полной длины на тело; при превышении тело пропускается
целиком, частичный кэш не используется. Сохраняются не более 32 ранжированных
кандидатов и не более 8 попыток создания на тело. На подготовку одного тела
отведено 30 секунд, на подготовку всех труб — 120 секунд. Эти проверки работают
между API-вызовами и не прерывают зависший внутри SolidWorks вызов.

Рабочая логика швеллеров/уголков, проверки существующих размеров, восстановление
настройки ввода значения и откат текущей неудачной попытки сохранены. Режим
касательных кромок не переключается, документы автоматически не сохраняются.

## Запуск

1. Импортируйте **FrameCutListDimensionsV3.bas** со стандартными ссылками
   SldWorks и SwConst. Это самостоятельный модуль; предыдущие модули не нужны
   как зависимости. Выполните **Debug → Compile**.
2. На копии чертежа выберите одну кромку или силуэтную кромку самой многотельной
   детали рамы. Вид должен использовать истинные размеры; конфигурация исходной
   детали должна соответствовать экземпляру сборки.
3. Запустите **`FrameCutListDimensionsV3.main`**. Имя модуля отличается от V2.
4. Сверьте отчёт по каждому телу. Подтверждённые старые размеры сохраняются;
   на чертеже с 17 размерами V2.2 они должны учитываться по реальным привязкам,
   а не только по совпадающему числу. Неоднозначные привязки могут остановить
   создание, чтобы избежать дубликатов.
5. Для подтверждения покрытия всех тел нужны полный журнал из TEMP и снимок вида.

## Размещение и проверка

По просьбе пользователя исследуется вынос за контур **измеряемой трубы**,
с учётом соседних элементов. В V3 размещение не менялось: новый алгоритм
свободных областей пока не реализован. См.
[вывод API-эксперта](docs/empty-space-dimension-placement.md).

V3 проходит статическую проверку и независимый разбор; это не компиляция VBA
и не запуск SolidWorks. Ускорение и обработку оставшихся двух тел необходимо
подтвердить нативным запуском. Успех V2.2 не является нативной проверкой V3.
