# Размеры всех тел рамы, включая профильные трубы

`FrameCutListDimensionsV2.bas` v2.2 — самостоятельный VBA-модуль для SolidWorks
2025. Он масштабирует подтверждённую одиночную пробу трубы на тела списка вырезов
**одной выбранной многотельной детали рамы**. Проушины, ножки и другие компоненты
сборки не образмеряются. Исходники предыдущей массовой версии и одиночной пробы
сохранены без изменений.

## Запуск

1. Замените прежний модуль V2 новым `FrameCutListDimensionsV2.bas` в VBA-проекте
   со стандартными ссылками SldWorks и SwConst. Выполните **Debug → Compile**.
2. На копии чертежа выберите **одну кромку или силуэтную кромку самой детали рамы**.
   Выбирать все тела не нужно. Дополнительное выделение рамки вида допускается.
3. Тип размеров вида должен быть **True / Истинный**. Исходная конфигурация детали
   должна соответствовать выбранному экземпляру сборки.
4. Запустите **`FrameCutListDimensionsV2.main`**.
5. Сверьте итог по каждому телу, реальные значения и привязки. Полный Unicode-журнал
   сохраняется в TEMP, путь отображается в итоговом окне. Для проверки первого
   массового запуска нужны этот журнал и снимок вида.

Макрос не сохраняет документы, не перестраивает модель, не обновляет список
вырезов и не переключает конфигурации. Подтверждённые существующие размеры
сохраняются и учитываются; неоднозначные старые привязки могут остановить создание
или исключить соответствующее тело, чтобы избежать дубликатов.

## Подготовка и две фазы создания

Кандидаты обоих типов собираются **до первого создания размера**. Режим отображения
касательных кромок не переключается ни при подготовке, ни при создании, ни на выходе.

1. **Обычные видимые рёбра.** Сохраняется рабочий путь для швеллеров и уголков:
   только выбранный экземпляр, точная идентичность исходного тела, прямое ребро
   полной длины `LENGTH` из списка вырезов.
2. **Границы скруглений трубы.** Для каждого оставшегося тела без обычных кандидатов
   грани берутся непосредственно из исходного тела списка вырезов, одним вызовом
   `Body.GetFaces`. Цилиндрические грани проверяются по одному разу; из их рёбер
   выбираются реальные прямые границы плоскости и цилиндра, равные полной длине
   тела. Повторные рёбра исключаются по native-идентичности. Обратный перевод
   коротких и дуговых рёбер чертежа в деталь больше не используется для этого поиска.

Источник кандидатов — геометрия исходного тела, включая скрытые грани. Это
осознанное расширение предыдущего поиска: видимость не заявляется и успешный
`SelectEntity` её не доказывает. Измеряется по-прежнему только выбранная деталь
рамы. Кандидат должен пройти выбор в нужном виде и проверки привязки, истинного
значения и отсутствия dangling. Отказ не вызывает переключения режима.

Каждый кандидат проверяется по исходному телу и физической длине. Для сборочного
вида применяется соответствующее ребро фактического экземпляра. При нескольких
подходящих границах предпочтение получает более наружная; это геометрическая
эвристика, окончательный результат проверяется после создания.
Опорная грань сразу берётся из исходного тела, чтобы не смешивать системы
координат чертежа и экземпляра сборки.

Подготовка ограничена: не более 2000 граней на тело, не более 32 сохранённых
кандидатов на тело и 30 секунд на поиск труб. При достижении лимита частичные
кандидаты текущего тела отбрасываются; причина отражается в отчёте. Проверки
времени выполняются между API-вызовами: они не могут прервать зависший внутри
SolidWorks COM-вызов. Число попыток создания остаётся ограниченным восемью на тело.

На выходе у каждого сохранённого нового размера повторно проверяются истинное значение, положение,
отсутствие dangling и числовой подмены. Неудачная попытка удаляет только свой
новый размер; при неподтверждённом удалении или неопределённом результате создания
дальнейшая работа останавливается. Уже успешные размеры сохраняются.

## Размещение

Рабочий поиск места рядом с контуром тела и калибровка перемещения в изометрии
сохранены. **Новый поиск свободных областей листа не реализован** по указанию
пользователя. Возможность и ограничения описаны в
[исследовании API](docs/empty-space-dimension-placement.md).

## Что проверено

- Пользовательский запуск V2.2 `FrameCutListDimensionsV2-radA8A7D.tmp.txt`
  завершился штатно: 17 размеров из 19, ошибок итоговой проверки нет. Два тела
  длиной 340 мм и 270 мм пропущены из-за общего лимита подготовки 30 секунд.
  Этот рабочий исходник сохранён. Оптимизация подготовки вынесена в новый
  самостоятельный [FrameCutListDimensionsV3](FrameCutListDimensionsV3.README.md).
- Пользовательский запуск предыдущей массовой версии: 11 корректных размеров
  швеллеров/уголков; 8 труб пропущены.
- Пользовательский запуск `FrameTubeDimensionTrial` v1.3: создан истинный размер
  трубы 1500 мм по реальной границе скругления, точная позиция сохранена после
  возврата исходного режима касательных кромок, dangling и override отсутствуют.
- V2.0: пользовательский журнал `FrameCutListDimensionsV2-radA1865.tmp.txt`
  содержит 19 тел, 11 созданных размеров и обрывается после начала этапа труб.
  Пользователь сообщил о трёх падениях SolidWorks без отчёта. Точный падающий
  COM-вызов не установлен: у старого кода не было промежуточных маркеров между
  переключением режима, перерисовкой и запросом опорных граней.
- V2.1 также завершилась падением. Журнал `FrameCutListDimensionsV2-rad36EB6.tmp.txt`
  содержит 4913 строк и обрывается между BEGIN/DONE вызова
  `GetCorrespondingEntity2(visible)` для ребра №481. До этого найдены 128 подходящих
  границ восьми труб, но продолжался обход остальных рёбер. Новые размеры в этом
  запуске ещё не создавались. Журнал показывает границу последнего вызова,
  но не внутреннюю причину сбоя SolidWorks.
- V2.2 исключает этот обратный обход и многократный поиск одних граней.
  Подготовка идёт непосредственно от исходных тел с ограничением объёма и времени.
  Сохраняются закрытие журнала после каждой строки и BEGIN/DONE-маркеры.
- V2.2: статическая проверка структуры и защит, сравнение рабочих вспомогательных
  процедур и независимый review. Это **не компиляция VBA и не запуск SolidWorks**.

В последнем пользовательском запуске V2.2 падение не повторилось; шесть труб
получили размеры непосредственно в исходном режиме отображения. Это результат
конкретного чертежа, а не гарантия для всех моделей. Покрытие двух оставшихся тел
ещё не подтверждено. Наличие итоговой строки не означает, что все тела получили размер.
