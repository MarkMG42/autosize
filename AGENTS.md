# Codex — autosize (SolidWorks 2025)

Прочитай **только** этот файл при входе. Для полноценной задачи затем
[правила координатора](engineering-knowledge/AGENTS.md).
Загрузка других папок запрещена, пока пользователь не указал задачу и область.

Роли Codex: `coder` (реализация), `api_expert` (проверка API),
`debugger` (поиск ошибок), зарегистрированы в [.codex/config.toml](.codex/config.toml).
Это помощники главного агента, не обязательные этапы каждой задачи.

Не открывай автоматически другие проекты, архивы, большие исходники, историю Git
или репозиторий `MarkMG42/Macro`. Не запускай агентов, тесты или команды,
пока пользователь не попросил начать работу. Не меняй файлы без задачи.
Когда необходим соседний каталог, объясни причину и спроси разрешение.

Не выдавай статические проверки за запуск SolidWorks. Подтверждённые рабочие
версии не перезаписывай. Git push — только с явного разрешения пользователя.
