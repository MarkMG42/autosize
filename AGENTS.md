# autosize — SolidWorks 2025 VBA

Текущий исходник: `FrameCutListDimensionsV3.bas` v3.0.
Подготовка использует кэш проверенных продольных рёбер вместо обхода граней.
Статические проверки пройдены; запуск V3 в SolidWorks и полное покрытие тел
ещё не подтверждены.

## Задача
Размер длины каждого тела списка вырезов одной выбранной многотельной детали
рамы на изометрическом виде сборки. Аксессуары не образмерять.
Длину брать из связанного LENGTH, проверять по геометрии; числовой override запрещён.
Будущая раскладка: за контур измеряемой трубы, с учётом соседних элементов.
Она пока не реализована.

## Работа
- Читай только файлы задачи; соседние проекты не открывай без разрешения.
- Сохраняй существующие размеры, проверки экземпляра/тела, истинного значения,
  dangling, координат, восстановление настроек и откат текущей попытки.
- Не переключай касательные кромки. Не возвращай массовый reverse-поиск
  коротких/дуговых рёбер: предыдущие реализации приводили к падению SolidWorks.
- Ускоряй подготовку повторным использованием проверенных исходных рёбер;
  увеличение тайм-аута само по себе не устраняет лишние обходы.
- Статическая проверка и interop не заменяют компиляцию и запуск в SolidWorks.
- Подагентов привлекай по задаче: coder меняет назначенный код;
  api_expert и debugger работают только чтением. Не запускай всех автоматически.
- Подтверждённый исходник сохраняй до проверки замены. Явное разрешение
  пользователя на очистку или замену имеет приоритет.
- Git push — только при разрешении пользователя. Отчёт краткий: изменения,
  проверки, ограничения. Не записывай историю неудачных итераций.
