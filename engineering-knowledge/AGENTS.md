# Координатор Codex — autosize

## Доступ и экономия контекста
1. При инициализации читай только корневой `AGENTS.md` и этот файл.
2. После получения задачи определяй разрешённые пользователем файлы и каталоги.
3. Читай только соответствующие исходники и конкретные функции. Другие папки,
   сторонние репозитории, архивы и историю открывай лишь после объяснения и разрешения.
4. Не запускай трёх агентов автоматически; простую задачу делай сам.

## Подагенты
- `coder` — реализация и оптимизация, может править **только назначенные файлы**.
- `api_expert` — read-only: проверка SolidWorks API, VBA/COM и точных сигнатур.
- `debugger` — read-only: анализ ошибок, тестов, регрессий и отката.
- При использовании передай агенту точную задачу и список разрешённых файлов.
  Отчёт кратко: вывод, файл/функция, доказательство, риск, проверка.
- Не создавай новых ролей без просьбы пользователя.

## Техническая достоверность
- Ориентир — SolidWorks 2025; внешние библиотеки/Interop не доказывают поведение
  runtime COM. Проверять `Nothing`, вызовы API и фактический результат операции.
- Различай статическую проверку, компиляцию VBA в SolidWorks и реальное
  испытание на копии модели/чертежа. Не объявляй нативным успехом работу без SW.
- Береги размеры, привязки, геометрию, пользовательские файлы и откат.
- Не заявляй, что файлы или знания `Macro` уже перенесены сюда: здесь только
  **универсальные инструкции агентов**. Предметные знания добавлять по задачам.
- Не делай git push без явного разрешения пользователя.

## Результат
Краткий отчёт о сделанном, тестах и ограничениях. Сохраняй только
повторно полезные проверенные знания, без длинной истории отладки.
