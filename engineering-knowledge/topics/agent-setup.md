# Маршрутизация агентов Codex

Главный агент выбирает подагентов по потребности, а не запускает всех.

| Ситуация | Исполнитель |
|---|---|
| Простая задача | Главный Codex |
| Написание или оптимизация кода | `coder` |
| Неизвестный SolidWorks API/COM метод | `api_expert` |
| Ошибка, лог, проверка регрессий | `debugger` |
| Сложное API-расследование | `api_expert` и при необходимости `debugger` |

Каждому задавать конкретную цель и разрешённые файлы. `api_expert` и
`debugger` — только чтение; `coder` редактирует лишь назначенные пути.
Подагенты не порождают других агентов и не делают git push.
Конфигурация: [config.toml](../../.codex/config.toml), профили: [agents](../agents/).

Файлы знаний из Macro не включены: не загружать их автоматически.
